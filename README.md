# Maia Cruz — landing

Sitio estático de Maia Cruz, creadora digital de surf, aventura y vida sana (personaje creado con IA).

- `index.html`: la página.
- `styles.css`: estilos.
- `main.js`: formulario de contacto para marcas (abre el correo con el mensaje listo). Cambia `CONTACT_EMAIL` por el correo real.

Incluye el widget de LemonSlice para conversar con Maia en vivo.

## Deploy en Render

Static Site, sin build command, publish directory `./`.
